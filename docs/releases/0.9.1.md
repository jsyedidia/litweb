# Litweb 0.9.1

Litweb 0.9.1 fixes PDF compilation when a page break occurs at the start of a
list in a document with mini-indexes. LuaLaTeX could previously stop with
`Something's wrong--perhaps a missing \item` even when the list was valid.

Mini-index columns now initialize their own paragraph settings, allowing the
interrupted list to continue normally. The fix applies to bulleted and numbered
lists. An optional LuaLaTeX regression test covers both forms; ordinary builds
and tests remain independent of a TeX installation.

After installing the update, regenerate LaTeX output to refresh the bundled
`litweb-latex/litweb.sty`, then compile the PDF again.

## Installing

Litweb requires Rust 1.97 or newer. From a checkout of this release:

```sh
make install
lw --version
```

The version command reports `Litweb version 0.9.1`. Direct Cargo installation
is also available:

```sh
cargo install --locked --force --path .
```

See the [README](https://github.com/jsyedidia/litweb/blob/v0.9.1/README.md)
and [user manual](https://github.com/jsyedidia/litweb/blob/v0.9.1/docs/manual.md)
for build instructions and output options.
